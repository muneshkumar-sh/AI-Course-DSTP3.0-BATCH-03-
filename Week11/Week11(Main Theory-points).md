### **--> LangChain*** LangChain is a framework that helps developers build applications powered by LLMs* Simplifies interaction between LLMs \& external data sources or APIs* focus on Modularity, Composability, integration* Core idea: "chain together" multiple LLM calls \& components into logical pipelines### **--> Retrieval-Augmented Generation (RAG)*** LLMs are powerful but limited by training data and content length* they can hallucinate, generate false or outdated information* RAG overcomes this by retrieving real data at query time
