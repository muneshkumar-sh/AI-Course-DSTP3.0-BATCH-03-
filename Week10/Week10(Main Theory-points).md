### **--> Computer Vision - Mathematical Foundations*** to process an image, a computer must treat it as a quantitative structure, not just a picture* Every digital image is a discrete, two-dimensional function representing light intensity* **Image as a Matrix:**  * A digital image is formally represented as a 2D matrix (or array)  * M x N matrix  * Iij represents the intensity value of the pixel at row i and column j### **--> Computer Vision - Edge Detection \& Filtering Techniques*** a fundamental technique in computer vision used to identify boundaries \& structural information in an image* Edges represent significant intensity changes, helping in object detection, segmentation, and contour analysis* detecting edges simplifies the image while preserving important features* **Sobel Filter** - first derivative method* **Laplacian Filter** - second derivative method### **--> Computer Vision - Morphological Operations (Erosion and Dilation)*** Erosion \& Dilation filters* part of Morphological image processing* used for shape analysis, noise removal, and object refinement* **Morphological image processing:**  * operates on binary or grayscale image  * based on set theory \& geometry  * focuses on shape-based transformation rather than pixel intensity  * key operations: Erosion \& Dilation* need **structuring element** for apply any filter  * a small matrix (kernel) that slides over image  * defines the neighborhood used for processing  * common shapes: square(3x3), circle, cross### **--> Computer Vision - Image Segmentation Fundamentals*** divide an image into meaningful regions* foundation for object detection, scene understanding, \& image analysis* image segmentation is the process of partitioning an image into multiple segments (sets of pixel)* each segment shares similar properties such as color, intensity or texture* helps computers identify objects \& boundaries in image* think of it as: "labeling each pixel with what it represent"* **Types:**  * Threshold-based segmentation -simple  * edge-based segmentation -boundary detection  * region-based segmentation -pixel grouping  * clustering-based (ML) segmentation -advanced### **--> Object Detection \& Segmentation - Advanced Concepts*** Advanced mathematical concepts (Yolo \& U-Net)* Understanding the math that powers visual understanding* **Yolo(You only look once):** Object detection* **U-Net:** Image segmentation* What are we solving?:  * Object detection: locate what \& where in an image  * Segmentation: Label each pixel according to class* Both rely on mathematical foundations:  * 1\. Convolutions  * 2\. Feature maps  * 3\. loss functions  * 4\. Optimization### **--> Generative AI*** **LLM**: Neural Network trained on massive text corpora* Understand and generate natural language using transformer architecture* Example: ChatGPT, Claude, Gemini* **How LLM works:**  * Learn context, grammar and reasoning by predicting the next token* **Generative AI:**  * AI that creates new data (text, images, code, audio, video) instead of just analyzing existing data by learning patterns from existing data, mimicking human creativity  * Built on foundation models trained on diverse multimodal data  * can perform unseen tasks via transfer learning### **--> Prompt Engineering 101 - Fundamentals \& Techniques*** Prompts mean instructions or questions given to an LLM* Output quality depends heavily on prompt clarity \& structure* Good prompts define role, context, \& desired output* **Example:**  * vague: "Explain AI"  * clear: "Explain AI in simple terms for a 10 year-old"* **Zero-Shot Prompting:**  * The model performs a task without prior examples  * relies on pre-training knowledge  * Example:    * Prompt: "Translate 'Good morning' into French"    * Output: "Bonjour"* **Few-Shot Prompting:**  * Provide a few examples in the prompt to guide the model  * Helps the model understand structure, tone, or style* **chain-of-thought Prompting:**  * Encourage model to think step by step  * boosts performance on reasoning  or multi-step problems  * prompts: "Lets reason step by step to solve this math problem"
