### **--> Hierarchical Clustering**

* Hierarchical Clustering is an unsupervised method that organizes data points into a hierarchy of nested clusters
* Does not require pre-specifying the number of clusters
* Builds a tree-like structure(dendrogram) showing relationship between points and clusters
* Useful for understanding natural groupings in data \& visualizing cluster hierarchies
* **Two Types:**

  * Agglomerative (bottom-Up)
  * Divisive (top-bottom)
* **Advantages**

  * Do not require specifying k upfront
  * provides visual representation via dendrogram
  * Flexible choice of distance \& linkage methods
* **Application:**

  * Gene expression analysis
  * Customer segmentation
  * Document Clustering



### **--> Hierarchical Clustering - Dendrograms \& Cluster Selection**

* Dendrogram is a tree diagram representing the hierarchy of clusters
* Each merge or split is represented by a branch connecting clusters
* height of the branch shows distance or dissimilarity between clusters





### **--> Principal Component Analysis (PCA) -Unsupervised Method**

* PCA is a dimensionality reduction technique
* Helps simplify datasets
* Reduce computational cost, remove noise
* **How works:**

  * transforms the original features into a new set of orthogonal axes called principle components
* **Mathematical Foundation:**

  * Eigenvector
  * Eigenvalues



### **--> Artificial Neural Networks (ANN)**

* Mathematical model inspired by the brain
* Made up of neurons organized in layers
* learn patterns from data
* used for: classification, regression, image recognition, NLP, etc.
* Key idea: ANN learns values of weights \& bias using training
* **ANN - Feedforward Neural Networks:**

  * A neural network where data flows only in one direction
  * input-> Hidden layers-> Output
  * No loops, no feedback connections, also called multi-layer perception -MLP
  * Uses activation functions (ReLU, Sigmoid, Tanh)
