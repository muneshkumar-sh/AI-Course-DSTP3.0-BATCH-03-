### **--> ANN - Logistic Activation Function*** **Activation function:**  * Decide whether a neuron should activate or not  * introduce non-linearity into the network  * Enable neural networks to learn complex patterns  * Applied after weighted sum + Bias* **Logistic (Sigmoid) Function:**  * One of the earliest activation functions  * Output between 0 \& 1  * Often used for binary classification### **--> ANN - Backpropagation Algorithm*** Backpropagation = algorithm to train neural networks  * measure errors(loss)  * computes gradients(partial derivatives)  * Updates weights to reduce error  * repeats until convergence* Learning by adjusting weights backward from the output layer* Backprop uses chai rule to compute gradients* Training = forward pass + backward pass### **--> Convolutional Neural Networks (CNN) -Deep Learning*** Type of deep neural network specialized for image \& spatial data* Use convolutional layers to automatically extract features* learns spatial hierarchies edges -> shapes -> objects* **Training a CNN:**  * Forward pass: input-> predictions  * loss calculation (error measurement)  * backpropagation (weight updates)  * iterative improvement using epochs### **--> Recurrent Neural Networks (RNN)*** designed to handle sequential data* Examples: time series, text, speech, videos* **Sequence Modeling:**   * Input: sequence of vectors  * Output: sequence or single output  * Goal: model dependencies across time steps
